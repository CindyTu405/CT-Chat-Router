- Highlight final decisions: offsets are into SOURCE markdown (half-open [start,end)); AI replies are never edited so anchor_text validation rarely fails (appending bottom titles only grows the end, shifting nothing). ONE-LEVEL branching only (parent_branch_id unused). Overlapping anchors → downgrade to bottom title entry (no nested highlight). Code-block anchors also get no inline highlight — bottom title entry instead. Inline highlight = wiki-link (file name = branch title, display text = anchor text); title editable only in right sidebar.

- Edit-last-message: INLINE edit (do NOT recall to main input box), then regenerate and DELETE the old turn to keep the main thread linear, with a warning in the input box. Only text-selection opens a real branch.
- Ghost branches: when a deleted turn was an anchor for other branches, those become orphaned (ghost).
