CT-Chat-Router · B14

套件漏洞升級

程式用到的第三方套件有已知漏洞。這份教學說明怎麼找出來、只升需要升的、升完怎麼確認沒弄壞。

1問題

V1-4c 用兩個工具掃描（2026-11-08）：

範圍工具結果影響
後端pip-audit11 個套件、66 筆正式站實際執行的程式，影響大
前端npm audit --omit=devvite、source-map-js，2 筆 high只在 build 時使用，正式站由 nginx 提供靜態檔，影響小

後端最重要的是 starlette（FastAPI 底下處理 HTTP 請求、cookie session 的那一層）和 python-multipart（解析表單上傳）。它們直接處理外部送進來的資料。

2概念：鎖檔

pyproject.toml 寫的是「可以接受的版本範圍」，例如 fastapi>=0.124.2。真正安裝的確切版本記在 uv.lock（前端是 package-lock.json）。Docker build 時照鎖檔安裝，所以每次部署裝到的版本都一樣。

這也代表：鎖檔不更新，漏洞就一直在。升級就是更新鎖檔，再重新 build。

3概念：只升需要升的

全部升到最新版（uv lock --upgrade）會動到 50 個套件，包括 openai 2 → 3、sqlalchemy 2.0 → 2.1 這類大改版，出問題時很難知道是哪一個造成的。

這次只升有漏洞的套件，以及因此必須跟著升的套件：

# 示意，實際由 implementer 執行
uv lock --upgrade-package starlette --upgrade-package fastapi \
        --upgrade-package python-multipart --upgrade-package cryptography \
        --upgrade-package urllib3 --upgrade-package anyio \
        --upgrade-package requests --upgrade-package idna --upgrade-package certifi

試算結果（2026-11-09 dry-run）：

套件現在升級後備註
starlette0.50.01.10.0大改版，舊的過時 API 被移除
fastapi0.128.00.162.2要跟著升才能用 starlette 1.x
python-multipart0.0.210.0.33
cryptography46.0.450.0.2authlib 用來驗證登入
urllib3、requests、idna、certifi、anyio小版本升級
風險：starlette 1.x 移除了一些舊寫法。本專案用的是 lifespan、SessionMiddleware、StreamingResponse，都是新寫法，但 slowapi（限流）和 authlib（OAuth）是第三方套件，是否相容要靠測試確認。

4步驟

  1. B14-1 後端：照上面升級鎖檔；重建本機 api 映像；跑全部 harness；再跑一次 pip-audit，確認剩下的漏洞數。
  2. B14-2 前端：npm audit fix（vite 7.3.6 → 7.3.7，同一個大版本）；npm run build；再跑一次 npm audit --omit=dev。
  3. 你的瀏覽器驗收：登入、登出、聊天串流、重新生成、分支，重點是登入（authlib + cryptography + starlette session）。

如果 slowapi 或 authlib 跟 starlette 1.x 不相容，就退一步：starlette 停在 0.x 最後一個修掉漏洞的版本，先上線，大改版留到 V1 之後。

5怎麼驗收

  • uv.lock 裡 starlette ≥ 1.3.1、python-multipart ≥ 0.0.31、cryptography ≥ 50.0.0（各自漏洞清單裡最高的修正版）。
  • pip-audit 對升級後的鎖檔：0 筆，或剩下的每一筆都寫明原因。
  • regenerate、branch_entries、auth、model_options、quota、pool、limits 七個 harness 全部 ALL PASS。
  • npm audit --omit=dev：0 筆；npm run build 通過。
  • 瀏覽器：GitHub 登入、登出再登入、聊天串流、重新生成、建立分支都正常。

6部署注意

正式站的 api 映像沒有掛載原始碼，git pull 之後要 sudo docker compose up -d --build 才會照新的鎖檔安裝。這批還有 V1-2 的 migration，記得跑 alembic upgrade head。
