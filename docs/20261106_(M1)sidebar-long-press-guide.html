手機側邊欄選單

手機沒有滑鼠，hover 不可靠。這份教學說明怎麼讓三點選單在手機上隨手可得，並加上長按。

1問題

側邊欄每一列的三點按鈕平常是透明的，要靠 group-hover 才顯示。這在手機上有兩個問題：

  • 沒有滑鼠，使用者看不到三點，也不知道有選單。
  • 按鈕只是透明，仍然點得到。點到列的右側時，可能打開選單，而不是進入對話。

2概念：透明不等於不能點

opacity: 0 只影響看不看得到，元素仍會接收點擊。要讓它真的點不到，還要加 pointer-events: none。

// 依視窗寬度分開（md = 768px 以上）
未選取的列  手機：透明、點不到        桌面：hover 才顯示
已選取的列  手機：常駐顯示、可點      桌面：hover 才顯示（維持現狀）
選單開啟中  手機與桌面都顯示

3概念：長按是自己算出來的

瀏覽器沒有通用的「長按事件」，要用計時器判斷：手指按下開始計時，時間到就打開選單；手指提早放開或開始滑動就取消。

4三個容易出錯的地方

狀況結果做法
長按放開後，瀏覽器可能再送出一次 click選單開了，同時又切換對話用一個旗標略過這次 click
iOS 長按後可能不送 click，旗標沒被清掉下一次正常點擊被吃掉每次 touchstart 都先重設旗標
瀏覽器本身也有長按行為選到文字，或跳出系統選單手機上關閉文字選取；touch 引發的 contextmenu 要擋掉，桌面右鍵不受影響
// 示意，實際程式由 implementer 撰寫
onTouchStart: 重設旗標；記下位置；500ms 後 → 打開選單、設旗標
onTouchMove:  移動超過 10px → 取消計時
onTouchEnd:   取消計時
onClick:      旗標為真 → 重設並略過；否則載入對話
